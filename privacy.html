1. Finalidad de la aplicación y procesamiento local de fotos

La Aplicación es una herramienta de gestión local de fotos. Solicita el permiso “Fotos y vídeos” (READ_MEDIA_IMAGES) para leer las imágenes de tu galería y ofrecer funciones como detección de fotos duplicadas, agrupación de fotos similares, organización por cronología y búsqueda local.

Puedes revocar el permiso de galería en cualquier momento desde los ajustes del sistema Android; tras la revocación, las funciones relacionadas con la galería dejarán de funcionar y la Aplicación no conservará ningún dato de tus fotos.

2. Recopilación de información y publicidad de Google AdMob

La Aplicación integra Google AdMob para mostrar anuncios dentro de la app. El SDK de AdMob recopila automáticamente la siguiente información para los servicios publicitarios:

  • ID de publicidad de Android (AD-ID)
  • Datos de interacción con anuncios: impresiones, clics y señales relacionadas con el rendimiento de los anuncios

Estos datos se utilizan para la entrega de anuncios, anuncios personalizados, medición del rendimiento y prevención del fraude publicitario.Todo el tratamiento de datos relacionados con anuncios lo realiza Google AdMob.

Puedes restablecer o desactivar el ID de publicidad en los ajustes del sistema del teléfono para desactivar los anuncios personalizados. Después de hacerlo, seguirás viendo anuncios no personalizados.

Aparte de los datos relacionados con anuncios que obtiene automáticamente el SDK de AdMob, la Aplicación por sí misma no recopila, almacena ni sube activamente ninguna otra información personal.
La Aplicación no recopila IMEI, Android ID, dirección MAC, ubicación, micrófono, contactos, historial de navegación, registros de ejecución, etc.

3. Servicio de terceros: Google AdMob

El único SDK de terceros integrado en la Aplicación es Google AdMob (servicio de publicidad). El tratamiento de datos de AdMob sigue la Política de Privacidad oficial de Google, que puedes consultar en:https://policies.google.com/privacy

4. Almacenamiento de datos

El contenido de las fotos se procesa solo temporalmente en la memoria del teléfono y nunca se guarda fuera. La Aplicación conserva únicamente una pequeña cantidad de datos de configuración en la caché local, que puedes borrar desde los ajustes de la Aplicación o desinstalándola. La Aplicación no sincroniza ni sube ningún dato del usuario a la nube.

El ID de publicidad y los datos de eventos publicitarios son procesados y almacenados por Google según sus propias normas de conservación de datos.
